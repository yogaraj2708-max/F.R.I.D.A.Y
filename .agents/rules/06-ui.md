# Rule 06: UI/UX & Tactical HUD Standards

1. **State-Truthful Animations**: The Arc Reactor, audio visualizer, and HUD indicators must strictly mirror actual application state (`IDLE`, `LISTENING`, `PLANNING`, `EXECUTING`, `VERIFYING`, `SPEAKING`, `ERROR`). Never trigger fake animations when nothing is processing.
2. **Instant Cancellation (Barge-in)**: Pressing `Esc`, clicking `■ Stop`, or uttering a new command must immediately silence audio synthesis and halt downstream generation.
3. **Responsive Frameless Chrome**: Keep the frameless glassmorphism window responsive at 60 FPS. Optimize canvas repaints in `QPainter` widgets.
4. **Theme Consistency**: All UI widgets must honor the dynamic palette engine (`Tactical Dark Cyan` and `Crisp Slate Light`) with smooth color transitions.
